# Report Format

Write in `output.language`. Use concise evidence for each decision and include public posting links.

## Run summary

Summarize the number of results, distinct jobs, new jobs, prior candidates rechecked, the time window, jobs checked in detail, and the number of recommendations in each category. Move search, pagination, and tool details to the coverage note when they affect the findings.

## Recommended

List jobs where the available evidence supports spending Connects. Show the posting link, score, client location, budget or rate, estimated effort and earnings, competition, Connects, reasons for the match, and main risks.

## Conditional recommendations

Use the same fields and add what the user should confirm or accept before applying. Start with conditions the user can realistically check, such as availability, portfolio evidence, location, or verified experience.

For a hidden budget, incomplete scope, or terms that can only be clarified after submission, recommend the job only if the existing evidence justifies the application cost. State how many Connects an application costs and that the client may not respond. Otherwise, record it as a non-recommendation.

## Prior recommendations and status changes

Summarize still-relevant jobs within the reminder window. Include current hiring and application status, the prior recommendation, and a relative link to the previous report. Record substantive changes such as a closure, revised budget, interview, or offer. Reuse the prior analysis and draft where the evidence is unchanged.

## Job analysis

For each recommended or conditional job, explain the client's need, whether the work starts from scratch or extends an existing system, and the main work and deliverables. Then cover the information below.

- Publication time, job type, budget, client location shown on the account, and hiring activity.
- Relevant evidence from the profile, reasons for each score, and delivery constraints.
- Suggested scope and price, estimated hours or duration, and earnings assumptions.
- Main unknowns, risks, and questions to resolve.
- Connects cost and whether applying is worthwhile. Use the available cost, any configured threshold, and the evidence from the posting.
- Local proposal drafts for the configured recommendation levels. Preserve the same facts and commitments across languages.

Use location as shown on the posting. Mark missing fields as unknown. When search results and job details disagree, prefer the details for live fields and retain search-only fields with their source.

For fixed-price work, divide the expected contract amount by estimated hours to calculate the effective hourly rate. For hourly work, multiply the proposed rate by estimated billable hours for gross earnings. Calculate earnings after the platform fee using the known fee or a range of verified fees from preferences. If the fee is unknown, show gross earnings and flag net earnings as unconfirmed. State whether taxes, currency conversion, withdrawal fees, or extra work are included. Rate confidence as high, medium, or low based on the scope, hours, and pricing evidence.

## Optional screening appendix

When enabled, include a few rejected jobs that illustrate the screening criteria. Summarize diagnostics only when they affect coverage or the interpretation of results.
