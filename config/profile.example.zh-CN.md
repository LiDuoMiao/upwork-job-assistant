# Upwork 能力档案模板

复制为 `config/profile.md` 后填写。这里的内容会参与筛选，也可能被用于投标草稿。只填写已确认的经历，并标明可以对客户披露的细节。优先使用可公开的项目描述，省略证件号、联系方式、凭证及受保密约束的客户信息。

## 职业定位与技能

- 目标角色与希望承接的项目类型：[填写]
- 主要技能及应用场景：[填写技能、做过的工作和可独立完成的部分]
- 相关工作经历：[填写可引用的职责、行业和经验。雇主名称与工作时间可按需省略]
- 教育或认证：[选填与目标项目有关、允许引用的内容]
- 需要额外确认的能力与暂不承接的工作：[填写]

## 可引用的项目经历

每个项目可记录以下内容。没有可确认的量化结果时，写清已交付的成果即可。

- 业务背景和需要解决的问题：[填写]
- 自己的角色、负责部分及团队分工：[填写]
- 关键技术判断、使用的技术和交付结果：[填写]
- 可公开的作品链接与披露限制：[选填]

**虚构填写示例，仅演示格式，不能作为投标经历引用。** 某内部设备借用工具原先用表格登记，团队需要防止重复预约。示例角色负责预约 API 和冲突校验，另一位成员负责页面。交付了可登记、归还和查询状态的模块。本例无外部作品链接。

- 可对外展示的作品与链接：[选填经过确认的公开材料]
- Proposal 可以引用的内容和需要再次确认的承诺：[填写]
